🇮🇩 印尼語 Flash Card

從單字清單勾選要複習的內容，開始 Flashcard 或測驗
備份涵蓋所有語言的單字表、翻譯、例句、聲調標記、⚠️ 待複習標記、已學會進度等，存成一個 JSON 檔下載。不含 API Key（安全考量，換裝置要自己重新輸入）、不含你自己的錄音（IndexedDB 音檔太大，錄音本來就是重錄就好）。還原會直接覆蓋目前資料，請小心操作。
Key 只會存在這台電腦的瀏覽器裡（localStorage），不會上傳到別的地方。用來讓 AI 幫新單字自動生成翻譯和測驗句。
用於「跑步聽力模式」把單字轉成真正的音檔（存在這台電腦，同一個字只會生成一次，之後重播不再花錢）。
幫已經有完整資料、但還沒有口語/難易度標籤（是這個功能上線後才有的欄位）的舊單字補上標籤，不會動到原本已經正確的意思/例句/測驗題。
埃及阿拉伯文專用：掃過勾選的字，判斷哪些是有固定口語對答的客套話（打招呼、道謝、道賀…），有的話把「對方通常會怎麼回」顯示在那個字下面。一般字彙不會有這行。
會依序處理目前勾選的每個字：補上例句、把發音（含中文意思的發音）都先生成好存起來。已經生成過的字會自動跳過，不會重複花錢。字多的話會跑很久，建議連 WiFi、出發前先跑完。
